# Coffee Fluid Lab

一个用 Three.js 和低分辨率三维数值求解器实现的交互式咖啡 / 牛奶混合实验。体渲染直接读取求解器的牛奶浓度场；没有预设旋涡、粒子路径或混合动画。

## 本地开发

需要 Node.js 22.12+（当前云环境验证版本：24.19）和支持 WebGL 2 / 三维纹理的现代浏览器。不需要 API Key、数据库或外部服务。字体随应用本地打包。

```sh
npm ci
npm run dev
```

在 Vite 输出的地址打开应用。开发服务默认监听所有接口。生产构建：

```sh
npm run build
npm run preview
```

## 操作

- 在俯视位置面板拖动，或使用 X / Z 滑块设置注入点；位置限制在杯内。
- 设置速度、倾斜角、水平角、持续时间，点击「开始注入」。倾斜角 0° 竖直向下，水平角从 +X 向 +Z 旋转。速度单位是杯径 / 模拟秒。
- 注入期间修改位置、速度和方向立即生效；持续时间在按下注入按钮时锁定，再次点击会重新计时。
- 「垂直射流」「偏心旋流」只设置注入参数，不播放预设运动。
- 拖动视图旋转，滚轮缩放；侧面和初始视角按钮恢复指定观察位置。
- 暂停 / 继续（空格）、重置实验（R）；键盘快捷键在输入控件和模型弹窗内不触发。
- 打开速度场显示求解速度的抽样箭头，箭头长度随速度变化。
- 默认 16³ 网格，可选 20³ / 24³；切换网格重置实验。重置保留注入参数和暂停状态。

## 物理模型

计算域宽度为 1 杯径，液体高度为 1.15，圆柱液体半径为 0.48。每方向有 N 个网格单元；圆柱外单元为固体。实际参与计算的单元少于 N³。

速度存储在 MAC 交错网格面上，浓度与压力存储在单元中心。每个模拟步为 1/30 秒；根据最大速度（含目标注入速度）和扩散稳定条件细分子步。

每个子步：

1. 使用二阶中点反向追踪、三线性插值进行速度半拉格朗日平流，并施加小幅线性阻尼（系数 0.025 / 模拟秒）。
2. 若正在注入，在液面下约 2.5 层单元、有限半径的局部区域补充浓度，并将速度向目标射流速度松弛。这是有限强度的动量源，不是预置流动场。
3. 固体接触面的法向速度归零；求解 `∇²p̂ = ∇·u*`，其中 `p̂ = Δt p / ρ`。用红黑 Gauss–Seidel 迭代 40 次，再做 `u = u* − ∇p̂`，近似满足不可压缩条件。
4. 使用投影后的速度半拉格朗日平流浓度，再用显式有限差分进行浓度扩散。固体邻居不参与扩散，形成零法向通量。插值在固体边缘重新归一化。浓度约束为 [0,1]。

### 边界与近似

- 杯壁采用阶梯状圆柱近似。杯壁、杯底和顶部固定液面均不允许穿透；切向边界采用自由滑移近似，不解析黏性边界层。
- **固定体积、刚性盖板近似**：注入在域内部补充被动示踪浓度和动量，不增加液体总体积。未实现真实入流 / 等量出流边界，不能解释为累计倒入体积。模型不模拟液面上升、自由表面、波浪或溅射。
- 两种液体等密度；无温差、密度浮力、表面张力或高精度湍流。下沉由射流动量造成；速度输运和压力反作用产生旋流、回流。
- 半拉格朗日平流稳定但有数值耗散，且**不严格保持浓度总量**。低分辨率会抹平细节。界面的浓度扩散系数范围为 0–0.001，默认 0.0003；分子扩散与数值混合不能等同。
- 有限压力迭代会留下非零散度，界面显示实际投影后 RMS 残差（单位为模拟秒⁻¹）。没有为了让诊断好看而将其归零。
- 渲染的颜色、吸收和局部梯度明暗是定性的光学近似，不是完整的折射 / 多重散射模型。杯壁为透明材质，牛奶分布来自真实三维浓度纹理。外部短奶柱只标识入口，液体内部没有视觉替代动画。

## 性能

求解器在 Web Worker 中运行，Three.js 在主线程读取浓度三维纹理并做光线步进体渲染。渲染上限约 30 FPS，与求解进度独立。

当前云机器的 Node.js 样本（连续注入 30 步，非浏览器帧率基准）中，每模拟步平均耗时约：16³ 39 ms、20³ 85 ms、24³ 173 ms。实际设备会不同。

计算慢时，模拟时间会慢于墙钟时间；不跳过物理步，也不更换成视觉动画。优先使用 16³；切换网格会重置，程序不会悄悄清除当前实验。初始化失败会显示 WebGL 错误信息。

## 验证

```sh
npm test          # 数值求解器，Node 内置测试运行器
npm run test:e2e # Playwright：真实 Worker + WebGL 与交互
npm run build    # 生产打包
```

浏览器测试优先使用 `/usr/bin/chromium`，否则使用 Playwright 浏览器（首次运行可执行 `npx playwright install chromium`）。云环境的 Chromium 测试使用 SwiftShader 软件渲染；这可检查渲染路径，不代表硬件加速性能。

数值测试覆盖：

- 压力投影降低散度、固体无穿透边界；
- 静止初态、重置、无强迫静止浓度的扩散质量通量；
- 下沉输运、上行回流和浓度有界；
- 注入位置、方向、速度、时长改变数值输出；
- 相反切向射流产生相反角动量；
- 最大注入参数下的有限数值、CFL 子步、停止注入后的持续流动。

浏览器测试覆盖：真实浓度增加和非零速度、暂停时间冻结、继续混合、时长结束、速度场、视角切换、重置、网格切换、模型说明以及移动布局。

## 结构

- `src/fluid.js`：无渲染依赖的三维 MAC 求解器。
- `src/worker.js`：模拟时钟、注入时长和可转移浓度快照。
- `src/scene.js`：玻璃杯、三维体渲染、轨道视角和速度箭头。
- `src/main.js` / `src/style.css`：实验界面、控件、状态和响应式布局。

这是第一版研究与教学实验，不是标定后的工程 CFD 工具。
